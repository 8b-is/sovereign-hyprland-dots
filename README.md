# sovereign-hyprland-dots (v0.5.0)

Sovereign Hyprland + Waybar + Systemd User Service backups for the 8b-is / Qwave / qUltraKotoro / ALEXIAI workstation.

## Tracked Configuration

- `hypr/hyprland.conf` — Sovereign Hyprland configuration
- `hypr/hyprland.lua` — Sovereign Hyprland Lua configuration
- `waybar/config.jsonc` — Waybar status bar layout and Qwave HUD integration
- `waybar/style.css` — Sovereign Deep Ocean / Cyan / Gold palette
- `systemd/user/*.service` & `*.timer` — Loopback bridges, `qwave-whisper.service` (`qUltraKotoro` `:8785`), Liquid-Rust (`:8786`), Qwave Ear daemon, and Wi-Fi auto-healer units
